Preparar antes: aplicação online, contas fictícias, dados de demonstração, SQL conectado, telas e testes prontos. A gravação Java deve ter até 15 minutos e todos participam. Se necessário, gravar vídeo separado de QA para detalhar os cenários.

Não apresentar conteúdo de docs/decisao-de-ia.md como integração executada no Java. Não afirmar deploy, testes Oracle ou Playwright aprovados antes de executá-los. O material de DevOps pertence à aplicação .NET.

Registrar as decisões: manutenção de MVC, separação por camadas, segurança por perfil e posse, fragmentos Thymeleaf, Flyway por banco, package com saídas CLOB e views sobre as mesmas tabelas. Usar exemplos concretos da tela.
